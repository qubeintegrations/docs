## Welcome

The API for QuBe Sync is intentionally small and focused. You **create connections** for your users, **send them to our onboarding url**, and then **queue requests or workflows** for QuickBooks on their behalf.

QuickBooks Desktop integration is a fundamentally asynchronous process, because your customer's QuickBooks is only reachable through the customer's Web Connector. Their Web Connector polls QuBe Sync, so we enqueue requests and send the result to you in a webhook the next time it connects. **Passing a `webhook_url` with your request** ensures you'll get the result (parsed and transformed into nice, clean JSON) `POST`ed to that URL, signed with `X-QUBE-Signature` — see the [Webhooks guide](/webhooks).

## Authentication

All API endpoints are authenticated using your Application's API key and Basic Auth. The API key should be entered as the username, and the password left blank.

## Webhooks

To protect yourself from timing attacks and other common API vulnerabilities, it's best practice to follow the [Webhooks Guide](/webhooks). It will show you how to verify the webhooks you're receiving are genuinely from QuBe Sync.
