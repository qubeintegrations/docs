Answers from QuickBooks arrive as a `POST` to the `webhook_url` you pass with each request, so QuBe Sync has
to be able to reach it, and `localhost` isn't reachable. For a sandbox app, the [CLI](/cli) forwards them to
your local app:

```bash
qube listen --forward-to http://localhost:3000/webhooks/qube --write-env .env
```

It prints your webhook URL, writes it into `.env` as `QUBE_WEBHOOK_URL`, and then prints a line for each
delivery with your app's answer:

```
Webhook URL for My App Dev (the same every time on this machine):
  https://qubesync.com/relay/rl_4f7k2m9q8t3w6x1z5c0v7b2n4h
Forwarding to http://localhost:3000/webhooks/qube. Ctrl-C to stop.
14:02:11  request 01JA…  response_received  → POST /webhooks/qube  200  41 ms
```

Pass that URL as your `webhook_url`. Your app reads it from `QUBE_WEBHOOK_URL`, so the same code sends your
real endpoint in production:

- **The URL stays the same** for this app on this machine, so it goes into `.env` once.
- **It's delivered as in production.** The body and the `X-QUBE-Signature` header reach your app byte for
  byte, so you [verify the signature](/webhooks#securing-your-endpoints) with the same
  `QUBE_WEBHOOK_SECRET` that `qube env` wrote.
- **Every webhook comes through:** request answers, a [workflow run](/workflows)'s webhooks and
  notifications, and [name index](/matching) events.
- **A path you add is kept.** A `webhook_url` of `$QUBE_WEBHOOK_URL/runs` goes to the `--forward-to` URL
  plus `/runs`.
- **Nothing else on your machine is exposed.** Only QuBe Sync's deliveries for this app come through, not
  requests from the internet, as a tunnel would let in.
- **When it isn't running,** a delivery fails and is retried like any other, and the request's page in the
  dashboard has **Resend webhook**.
- `qube listen` works for sandbox apps only, and `--json` prints one line per delivery for a script or an
  agent. See [the CLI](/cli#receive-webhooks-locally) for its flags.

## Without the CLI: a tunnel

A tunnel gives your local server a public HTTPS address. Set `QUBE_WEBHOOK_URL` to its URL plus your
webhook route.

<CodeGroup>
```bash Cloudflare Tunnel
# https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/
cloudflared tunnel --url http://localhost:3000   # your app's port
```

```bash ngrok
# https://ngrok.com
ngrok http 3000   # your app's port
```
</CodeGroup>
